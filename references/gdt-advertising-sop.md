# 腾讯广告规范投放 SOP（批量新建）

## 1. 适用范围与边界

适用于腾讯广告「批量新建」场景，为一个或多个账户按统一规范搭建广告。

- 本 SOP 结束于「生成预览广告」并完成核对。
- 点击最终「提交」会在外部平台创建广告，必须由操作人当次明确确认后执行。
- 当账户、产品、品牌形象或落地页不满足统一配置条件时，停止使用「全部相同」或「统一配置」，改为按账户分别配置。

## 2. 开始前准备

先向需求方收集并核对以下信息；不要沿用上一项目的账户或资源。

| 项目 | 必填信息 |
| --- | --- |
| 账户 | 主体名称、账户 ID、账户数量 |
| 产品 | 产品名称或搜索关键词 |
| 品牌形象 | 用于搜索的主体关键词 |
| 定向 | 定向模板名称 |
| 素材 | 素材目录、时间范围、筛选指标和阈值 |
| 文案 | 要使用的完整文案原文 |
| 落地页 | 每个账户对应的落地页名称 |
| 出价预算 | 出价区间与一键起量预算 |

### 默认配置

| 配置项 | 规则 |
| --- | --- |
| 产品搜索关键词 | `1`；首次新建广告选择名称匹配 `1` 的产品 |
| 定向模板 | `6.3-腾讯-通投-fsh` |
| 品牌形象 | 使用主体关键词搜索，默认选择搜索结果第 1 条 |
| 素材目录 | `广点通-通信素材` |
| 素材筛选 | 近 7 天；花费 `>= 1`；目标转化量 `>= 1` |
| 文案 | `解锁福利,限时获取`、`号码提交,解锁福利` |
| 出价 | 随机出价 `110–130`；一键起量预算 `200` |

## 3. 搭建流程

### 步骤 1：导入并选择账户

1. 进入「批量新建」，在媒体账户区域点击「更换」。
2. 筛选方式选择「账户 ID」。
3. 粘贴账户 ID，每行一个纯数字 ID。
4. 在查询结果中直接勾选对应账户的复选框。
5. 核对主体、账户数量和投放链路后，点击「确定」。

**核对点：** 已选账户数与需求方提供的数量一致。

### 步骤 2：新建广告与营销内容

1. 点击「新建广告」。
2. 先选择优化目标：进入「更多目标」，在搜索框中搜索 `表单预约`，选择对应目标。
3. 推广产品选择「运营商产品」，承接方式选择「页面跳转」。
4. 进入「选择产品」，分配规则选择「全部相同」。
5. 若出现来源账户提示，在提示内选定已导入账户作为来源账户，勾选确认后点击「确定」。
6. 在产品搜索框输入 `1`，选择符合规则的产品，并确认同步至全部账户。

**核对点：** 产品已显示在已选区域，且应用范围为全部目标账户。

### 步骤 3：设置广告版位

1. 版位选择「智能版位」。
2. 探索策略选择「稳步探索」。
3. 仅保留以下三类版位：
   - 「微信公众号与小程序」：勾选微信公众号与小程序、微信新闻插件。
   - 「腾讯平台与内容媒体」：勾选 QQ 浏览器、QQ/腾讯音乐及游戏、腾讯新闻、腾讯视频。
   - 「腾讯营销联盟」。
4. 不选择微信视频号、微信朋友圈、腾讯营销电脑端。

**核对点：** 三个目标版位均处于选中状态；切换策略后如选项被清空，重新勾选再继续。

### 步骤 4：设置转化

1. 转化接入类型选择「API 上报」。
2. 转化目标点击「更多目标」，搜索 `表单预约`，选择「优投-表单预约」。
3. 转化分配规则选择「全部相同」。
4. 转化归因点击「快速选择」，选择「点击归因」。
5. 深度转化、深度目标和深度辅助保持关闭。

**核对点：** 已选目标明确显示为表单预约，归因为点击归因。

### 步骤 5：设置出价、预算与广告名称

1. 出价方式选择 `oCPM`，拿量策略选择「稳定拿量」，分配规则选择「全部相同」。
2. 选择「随机出价」，最小值填 `110`，最大值填 `130`。
3. 开启「一键起量」，预算填 `200`；日预算选择「不限」。
4. 投放时间选择「长期投放」，投放时段选择「不限」，广告状态保持「开启」。
5. 广告名称使用：

```text
智版-公众号+平台+联盟-<日期>_<时分秒><动态标号>
```

日期、时分秒和动态标号必须由名称输入框下方的通配符控件插入，不能手输尖括号文字；动态标号起始值为 `1`。

### 步骤 6：应用定向模板

1. 选择「手动定向」，分配规则选择「全部相同」。
2. 搜索并勾选 `6.3-腾讯-通投-fsh`。
3. 确认已选模板数为 `1` 后，点击「确定」应用至全部账户。

### 步骤 7：设置创意基本信息

1. 创意形式选择「组件化创意」，创意分配规则选择「全部相同」。
2. 品牌形象跳转选择「自定义」。
3. 按主体关键词搜索品牌形象，例如主体含「云启」则搜索 `云启`，含「瑞利」则搜索 `瑞利`。
4. 搜索完成后默认勾选第 1 条；确认右侧已选状态后点击弹窗内「确定」。
5. 主跳转类型选择「自定义落地页」，嵌套落地页类型同样选择「自定义落地页」。
6. 「按钮文案」下拉框选择「立即领取」。
7. 相似素材 AI 处理关闭，创意默认状态开启。

### 步骤 8：筛选并添加图片素材

1. 在「手动选取素材」中，多账户分配规则选择「平均分配」。
2. 创意组分配规则选择「平均分配」。
3. **创意组素材上限选择 `1`。** 页面中显示的素材数量或创意组数量只是结果，不能据此把上限改为其他数值。
4. 从创意组上方的全局「批量添加」下拉框选择「添加图片」；不要进入单个创意组内的「添加素材」。
5. 素材目录选择 `广点通-通信素材`。
6. 关闭「上传时间」日期范围筛选。
7. 点击「自定义指标与时间」，时间选择「近 7 天」。
8. 点击花费旁的筛选，选择「符合以下所有条件」，设置：
   - 花费 `>= 1`
   - 目标转化量 `>= 1`
9. 分页改为 `100条/页`，勾选素材表格左上角复选框，全选筛选结果。
10. 核对已选数量与筛选结果一致后，点击提交添加并等待素材写入完成。

**核对点：** 两项分配规则均为「平均分配」，创意组素材上限为 `1`，并且素材由全局批量添加入口写入。

### 步骤 9：配置广告文案

1. 手动文案区的分配方式保持「全账户复用」。
2. 点击「还可以添加」新增第二个独立输入框，分别填写两条文案：
   - `解锁福利,限时获取`
   - `号码提交,解锁福利`
3. 开启「多文案测试」。
4. 在测试选择页将「创意文案上限」设为 `2`，仅勾选上述两条文案。
5. 确认右侧已选数量为 `2/2` 后点击「确定」。

**核对点：** 预览中每个创意均显示「文案：已选 2 条」。

### 步骤 10：配置落地页

1. 打开「选择落地页」，先比对需求方提供的账户—落地页映射。
2. 若所有账户的落地页名称完全一致，选择「统一配置」，搜索完整落地页名称，勾选后确认右侧显示 `1/1`，再点击「确定」。
3. 若账户落地页不一致，选择「按账户分配」，逐账户搜索、勾选和核对。

**核对点：** 搜索到结果不代表已选择，必须勾选表格行并确认右侧已选数量变化。

### 步骤 11：生成预览并核对

1. 确认素材已生成创意组、每个创意已选 2 条文案、落地页已覆盖所有账户。
2. 点击「生成预览广告」，等待生成完成。
3. 在预览中逐项核对账户、产品、版位、转化、出价、定向、品牌形象、按钮、素材、文案、落地页和广告名称。
4. 预览无误后，向操作人说明提交的平台、账户数和即将创建广告的影响，获得明确确认后才可点击最终「提交」。

## 4. 常见问题与处理

| 场景 | 正确处理 |
| --- | --- |
| 粘贴账户 ID 后没有结果 | 清除空格、全角字符和非换行分隔符；整理为每行一个纯数字 ID 后重新导入。 |
| 产品搜索为空 | 从最后一页开始向前逐页查看；不能只检查第一页。 |
| 「全部相同」弹出来源账户确认 | 必须选择来源账户并勾选确认后点击确定，不能直接关闭弹窗。 |
| 切换「稳步探索」后版位被清空 | 重新勾选三个指定版位后再保存。 |
| 搜不到表单预约 | 确认已进入「更多目标」，等待列表刷新后再搜索。 |
| 定向、品牌、落地页只搜索未生效 | 在结果行勾选后，确认右侧已选数量变化，再点击确定。 |
| 素材页没有「日均转化」 | 使用当前页面可选的「目标转化量」作为本 SOP 的筛选指标。 |
| 全选素材只选中一页 | 先改为 `100条/页`，再勾选左上角全选。 |
| 出现相似素材或风险提示 | 先核对提示素材是否属于本次筛选结果；确认保留后选择「忽略风险，继续」，否则移除并重新核对数量。 |
| 两条文案被识别为一条 | 不要在同一输入框换行；使用「还可以添加」创建两个独立输入框。 |
| 多文案测试默认只能选一条 | 将「创意文案上限」从 `1` 调为 `2`，再确认右侧为 `2/2`。 |
| 广告名称提示缺少时间或标号通配符 | 从「插入更多」插入日期、时分秒和动态标号；动态标号起始值为 `1`。 |
| 页面无即时反应 | 等待搜索结果、已选数量、成功提示或下一步按钮状态出现；不要按固定秒数盲目继续。 |

## 5. 提交前检查清单

- [ ] 目标账户已导入、勾选，主体和数量正确。
- [ ] 已先选择优化目标；产品已按规则同步至全部账户。
- [ ] 智能版位、稳步探索和指定三类版位配置正确。
- [ ] 转化目标为表单预约，归因为点击归因。
- [ ] 随机出价为 `110–130`，一键起量预算为 `200`。
- [ ] 长期投放、时段不限、广告状态开启；名称中的日期、时分秒、动态标号均为系统通配符。
- [ ] 定向模板为 `6.3-腾讯-通投-fsh` 且已实际应用。
- [ ] 品牌形象、按钮文案「立即领取」、落地页均已实际选中并确认。
- [ ] 素材目录、近 7 天、两项筛选条件、每页 100 条均已核对。
- [ ] 多账户分配和创意组分配均为「平均分配」，创意组素材上限为 `1`。
- [ ] 文案恰为两条指定文案，多文案测试已开启并选择 `2/2`。
- [ ] 预览内容无误，并已取得当次最终提交的明确确认。

## 6. 自动化实现要求

1. 将账户、产品、品牌关键词、落地页映射、文案、出价和预算做成输入参数，不写死在脚本中。
2. 每次点击、输入或选择后，读取可见的成功状态、已选数量或下一步状态；不要只依赖固定等待时间。
3. 对产品分页、来源账户确认、筛选结果、弹窗确认和资源写入设置显式校验点。
4. 账户、产品、品牌、落地页、权限或白名单不匹配时，停止并输出异常清单。
5. 自动化默认停在预览阶段；最终提交必须有人工明确确认，例如 `CONFIRM_SUBMIT`。
